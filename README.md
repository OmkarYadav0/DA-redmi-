# DA-redmi-
Redmi Smartphone Consumer Analytics

Project Overview

This project analyzes simulated Redmi smartphone survey data to understand customer demographics, purchase trends, preferred models, pricing preferences, brand awareness, and customer satisfaction.

Objectives

- Analyze customer demographics and buying behavior.
- Identify popular Redmi smartphone models.
- Study purchase factors and sales channels.
- Compare Redmi with competing brands.
- Evaluate customer satisfaction and brand loyalty.

Tools & Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

Key Insights

- Price and value for money are the main purchase factors.
- Amazon and Flipkart are major purchase channels.
- North India shows the highest demand in the sample.
- Customer satisfaction averages 4.15/5.

Dataset

The project uses a simulated survey dataset of 850 respondents. The results are illustrative and do not represent verified Redmi sales figures.

Conclusion

This project provides insights into Redmi consumer preferences and helps identify opportunities for better marketing, customer satisfaction, and retention.
